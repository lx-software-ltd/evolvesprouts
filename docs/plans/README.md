# Plans

Yellow and red work leaves a plan in this directory before implementation. Copy [`_template.md`](_template.md) to a kebab-case file named for the change. Write the plan in simple future tense. Delete or mark the plan done in the pull request that finishes the work.

Green work does not need a file here. Summarise it in the pull request.
